## Executive Summary

Modern enterprise mobile applications—such as our **[Flutter Monorepo](https://github.com/MJ-BH/blueprint-project-flutter)** and **[Android Clean Architecture](https://github.com/MJ-BH/android-basic-clean-architecture)** blueprints—require robust backend microservice platforms capable of serving file hierarchies, stateless JWT authentication, asynchronous event processing, and multi-cloud object storage.

The **[microservices-blueprint-architecture](https://github.com/MJ-BH/microservices-blueprint-architecture)** repository delivers an enterprise backend reference platform published across 4 specialized technology branches:

1. **`master` (or `main`)**: Express.js JavaScript Microservices (`api-gateway`, `auth-service`, `explorer-service`, `email-service`, `url-builder-service`).
2. **`refactor/typescript`**: Strongly-typed Node.js & Express TypeScript Microservices.
3. **`spring-boot-java`**: Enterprise Java 17 Spring Boot 3 Microservices (Spring Security, Spring Data JPA, H2/PostgreSQL).
4. **`spring-boot-kotlin`**: Modern Kotlin 2.0 Spring Boot 3 Microservices with Kotlin Coroutines and Flow.

## 🗄️ Multi-Storage Provider Integration

Mobile clients upload documents via pre-signed URLs generated by `url-builder-service`:

### 1. Cloudflare R2 Storage (`CloudflareR2Provider`)
```javascript
// Node.js / TypeScript R2 Pre-Signed Upload URL
const command = new PutObjectCommand({
    Bucket: process.env.R2_BUCKET_NAME,
    Key: fileKey,
    ContentType: contentType
});
const presignedUrl = await getSignedUrl(r2Client, command, { expiresIn: 900 });
```

### 2. Amazon S3 Storage (`AmazonS3Provider`)
```java
// Java Spring Boot S3 Pre-Signed Upload URL
GeneratePresignedUrlRequest request = new GeneratePresignedUrlRequest(bucketName, fileKey)
    .withMethod(HttpMethod.PUT)
    .withExpiration(new Date(System.currentTimeMillis() + 15 * 60 * 1000));
URL presignedUrl = s3Client.generatePresignedUrl(request);
```

### 3. Local NAS Server Storage (`LocalStorageProvider`)
Provides a streaming HTTP fallback for private server installations.
